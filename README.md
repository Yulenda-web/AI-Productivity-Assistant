Build a modern, professional CRM and Call Centre Management platform called "Booster Hub".

IMPORTANT:

Use the uploaded Booster Hub CRM image as the actual application logo wherever the logo appears. Do not create, replace or redesign the logo.

Brand colours:

- Navy blue

- Green

- White

- Light grey

The platform should feel like a professional enterprise CRM/helpdesk system inspired by the workflows of MIP, Jira and Freshdesk, but use original Booster Hub branding and UI.
